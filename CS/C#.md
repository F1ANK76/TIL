# String
- 정의: 참조 타입(Reference Type)이며 매니지드 힙(Managed Heap) 메모리에 할당되고, 한 번 생성되면 값을 변경할 수 없는 불변(Immutable)의 특징을 가집니다
- 문제 : 문자열을 수정하거나 합산할 때마다 기존 데이터가 수정되는 것이 아니라, 매번 새로운 문자열 객체가 힙에 생성되므로 이전 데이터들이 가비지로 쌓여 잦은 GC 렉을 유발
- 해결 : 유니티 기준, 내부에 가변 배열 구조를 가진 StringBuilder를 활용하여 버퍼를 통해 문자열 연산 시 발생하는 가비지 생성을 방지
- 추가 정보 : StringBuilder 자체를 매번 new로 생성하면 이 또한 가비지가 되므로, 클래스 멤버 변수로 캐싱하여 Clear()로 내부 버퍼만 초기화해 재사용해야 완벽한 최적화(Zero-Alloc)가 가능
