# Array란?
- 같은 타입의 데이터를 연속된 메모리 공간에 저장하고 인덱스로 접근하는 고정 크기 배열 자료구조
- 사용 이유 : 같은 타입의 여러 데이터를 하나의 변수로 관리하기 위함
- 특징 : 고정 크기
- 시간복잡도 : 인덱스 접근 시 O(1), 순차 검색 시 O(n)

# List란?
- 같은 타입의 데이터를 연속된 메모리 공간에 저장하고 인덱스로 접근하는 동적 배열 자료구조
- 사용 이유 : 데이터 개수가 변할 때 유연하게 관리 가능
- 특징 : 필요에 따라 크기 조정 가능
- 시간복잡도 : 인덱스 접근 시 O(1), 순차 검색 시 O(n), 중간 삽입/삭제 시 O(n), 끝에 데이터 추가 시 O(1) 또는 O(n)

# Linked List란?
- 각 노드가 데이터와 다음 노드의 주소(참조)를 가지고 연결된 자료구조
- 사용 이유 : 데이터의 삽입과 삭제를 효율적으로 처리하기 위함
- 특징 : 데이터가 메모리상 연속적으로 저장되지 않아도 됨
- 시간복잡도 : 특정 위치 탐색 O(n), 알고 있는 노드 위치에서 삽입/삭제 O(1)
- 종류 : 단일 연결 리스트, 이중 연결 리스트

# Dictionary란?
- Key와 Value를 한 쌍으로 저장하고 Key를 이용해 Value에 빠르게 접근하는 자료구조
- 사용 이유 : 특정 Key에 대응하는 데이터를 빠르게 찾기 위함
- 특징 : Key는 중복될 수 없으며, Value는 중복될 수 있음
- 시간복잡도 : 데이터 검색/삽입/삭제 평균 O(1), 최악 O(n)
- 충돌 : 서로 다른 Key가 같은 해시 인덱스를 가리킬 때 발생
- 해결 : 버킷 배열의 크기를 소수로 정하고, 해시값을 버킷 크기로 나머지 연산하여 충돌을 줄임
