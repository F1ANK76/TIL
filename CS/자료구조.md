# Array
- 같은 타입의 데이터를 연속된 메모리 공간에 저장하고 인덱스로 접근하는 고정 크기 배열
- 특징 : 고정 크기
- 시간복잡도 : 인덱스 접근 시 O(1), 중간 삽입/삭제 O(n)
- 사용 예시 : 고정된 스킬 슬롯

# List
- 같은 타입의 데이터를 연속된 메모리 공간에 저장하고 인덱스로 접근하는 동적 배열
- 특징 : 배열 기반 동적 크기
- 시간복잡도 : 인덱스 접근 시 O(1), 마지막 추가는 평균적으로 O(1), 중간 삽입/삭제 O(n)
- 사용 예시 : 몬스터, 인벤토리 아이템, 파티원 목록 

# Linked List
- 각 노드가 데이터와 다음 노드의 주소(참조)를 가지고 연결된 자료구조
- 특징 : Node들이 서로 연결, 캐시 효율이 떨어져서 잘 사용하지 않음
- 시간복잡도 : 위치를 알고 있다면 삽입/삭제 O(1)

# Hash Table
- Key를 해시 함수에 넣어 나온 해시값을 이용해 데이터의 저장 위치를 결정하는 자료구조
- 사용 이유 : Key를 이용해 데이터를 빠르게 저장하고 검색하기 위함
- 특징 : Key → 해시값 → 버킷 인덱스 순서로 저장 위치를 결정
- 시간복잡도 : 검색/삽입/삭제 평균 O(1), 최악 O(n)
- 충돌 : 서로 다른 Key가 같은 버킷 인덱스를 가리킬 때 발생
- 해결 : 충돌한 데이터를 별도로 관리하여 같은 버킷에서 Key를 비교하는 등의 방식으로 처리

# Stack
- 데이터를 후입선출(LIFO) 방식으로 저장하는 자료구조
- 특징: 가장 나중에 들어온 데이터가 먼저 나감
- 시간복잡도: O(1)
- 사용 예시: UI 화면 이동 기록 관리

# Queue
- 데이터를 선입선출(FIFO) 방식으로 저장하는 자료구조
- 특징: 가장 먼저 들어온 데이터가 먼저 나감
- 시간복잡도: O(1)
- 사용 예시: 스킬 이펙트 재생 대기열
