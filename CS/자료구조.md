# Array란?
- 같은 타입의 데이터를 연속된 메모리 공간에 저장하고 인덱스로 접근하는 고정 크기 배열 자료구조
- 사용 이유 : 같은 타입의 여러 데이터를 하나의 변수로 관리하기 위함
- 특징 : 고정 크기
- 시간복잡도 : 인덱스 접근 시 O(1), 순차 검색 시 O(n)

# List란?
- 같은 타입의 데이터를 연속된 메모리 공간에 저장하고 인덱스로 접근하는 동적 배열 자료구조
- 사용 이유 : 데이터 개수가 변할 때 유연하게 관리 가능
- 특징 : 필요에 따라 크기 조정 가능
- 시간복잡도 : 인덱스 접근 시 O(1), 순차 검색 시 O(n), 중간 삽입/삭제 시 O(n), 끝에 데이터 추가 시 O(1) 또는 O(n)
