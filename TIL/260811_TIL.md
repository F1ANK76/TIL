# One-Page GDD

* **게임 제목** : Ultima Squad Re:Design

* **장르** : 방치형 RPG

* **한 줄 소개** : 메이플스토리의 「울티마 스쿼드」를 재해석하여 방치형 성장과 직접 조작의 재미를 결합한 RPG

* **핵심 테마** : 방치와 직접 조작이 공존하는 성장형 RPG

* **코어 루프** : 방치 사냥 → 재화 획득 → 능력치 성장 → 상위 스테이지 진입 → 보스 전투 → 다음 스테이지 도전

* **세계관 요약** :
  몬스터가 출몰하는 지역을 탐험하며 점점 강한 적과 보스에 도전하는 모험가의 이야기.
  평상시에는 자동으로 몬스터를 처치하며 성장하지만, 강력한 보스와의 전투에서는 직접 조작하여 공격을 피하고 패링하며 돌파한다.

* **주인공 이름·설정·목표** :
  이름 : 플레이어
  설정 : 몬스터를 사냥하며 성장하는 전투원
  목표 : 각 지역의 강력한 보스를 처치하고 더 높은 스테이지로 진입한다.

* **핵심 시스템** :

  * **방치 사냥** : 자동으로 몬스터를 공격하고 재화를 획득
  * **성장 시스템** : 획득한 AP를 공격력·체력 등에 투자
  * **스테이지 시스템** : 성장할수록 더 강한 몬스터와 지역에 도전
  * **보스 전투** : 자동 사냥과 달리 직접 조작하여 보스의 공격에 대응
  * **패링 시스템** : 보스의 공격 전조를 보고 타이밍에 맞춰 패링
  * **보상 시스템** : 보스 처치 후 성장 재화를 획득하고 다음 단계로 진행

* **레퍼런스 게임** : 메이플스토리 「울티마 스쿼드」

* **에셋 리스트** :

  * 플레이어 캐릭터
  * 일반 몬스터
  * 보스 캐릭터
  * 무기 / 장비
  * 전투 이펙트
  * 스테이지 배경
  * UI 리소스
  * 사운드 / 효과음
