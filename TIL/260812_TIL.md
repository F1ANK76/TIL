# 울티마 스쿼드 리디자인 프로젝트 버그 및 수정

1. 엘리트 잡고 다음 스테이지 가도 게이지가 100%로 남아있던 문제

원인: 엘리트 처치 시 연출용으로 게이지를 100%로 보여주게 했는데, 다음 스테이지로 넘어갈 때 실제 내부 값(0)으로 다시 동기화해주는 코드가 없었음
해결: ShowBannerThenSpawn()에 리싱크 호출 추가
2. Hovl Studio 이펙트들이 전부 보라색(에러 컬러)으로 렌더링

원인: 다운받은 에셋 머티리얼들이 Built-in 렌더 파이프라인 전용 셰이더를 쓰는데 프로젝트는 URP라 호환 안 됨. 데모 씬의 더미 캡슐들도 유니티 기본 Default-Material(Standard 셰이더) 사용
해결: Convert Selected Built-In Materials to Current SRP 메뉴로 34개 머티리얼 일괄 변환 + 캡슐은 URP Lit으로 재할당
3. Unity MCP 연결이 안 됨

원인: 이 Claude Code 세션이 켜져 있는 상태에서 나중에 Unity MCP 서버가 떴음. MCP 연결은 세션 시작 시점에만 맺어짐
해결: 세션 재시작으로 해결
4. 패링 실드/텔레포트 이펙트 중심이 플레이어 중심과 안 맞음 (2번 발생)

원인: 이펙트 프리팹 내부에 이미 Y축 오프셋이 들어있는데 그걸 감안 안 하고 배치함
해결: 오프셋만큼 반대로 이동해서 실제 중심을 맞춤
5. 궁극기 게이지가 전혀 안 차오르는 것처럼 보임

원인: 제가 미리보기 끝나고 "0으로 리셋"한다며 호출한 코드가, 게이지의 "전체 너비" 기준값 자체를 0으로 덮어써서 씬에 영구 저장해버림 — 그래서 매번 0×비율=0이 되는 상태였음
해결: 전체 너비를 런타임에서 유추하지 않고 별도 고정값으로 분리
6. 몬스터가 죽었는데도 평타 VFX가 계속 재생됨

원인: 궁극기 발동 중 평타를 막으려고 CombatLoop.enabled = false로 껐는데, 이게 OnDisable()을 타면서 "몬스터 죽음" 이벤트 구독까지 해제해버림. 하필 궁극기 데미지로 몬스터가 죽는 순간이 꺼져있는 타이밍이라 죽었다는 걸 전달받지 못해서 죽은 몬스터를 계속 공격 대상으로 붙잡고 있었음
해결: enabled 대신 이벤트 구독에 영향 없는 IsSuspended 플래그로 교체
7. 평타 치는 도중 패링 눌러도 그 평타와 VFX가 안 끊기고 같이 나감

원인: 패링이 애니메이터 상태만 바꿨을 뿐, 이미 예약된 데미지 코루틴이나 슬래시 VFX 코루틴은 그대로 진행되게 놔뒀음
해결: WeaponSwing.CancelSwing() / CombatLoop.CancelPendingAttack() 추가해서 패링 누르는 즉시 취소
